    History

      How it works

      A polynomial is a list of coefficients. An array is a list with numbered positions, so the two fit together neatly.

      Storage rule

      The coefficient of xk is stored at index k. The array length is always degree + 1, and missing powers hold 0.

      So 3x2 + 2x + 5 becomes [5, 2, 3].

      Why arrays?

      • Reading the coefficient of any power takes one step: P[k].
      • Adding two polynomials is a single loop over matching indexes.
      • The cost is wasted space for sparse polynomials such as x100 + 1.

      Algorithms

      Addition

      R[k] = P[k] + Q[k]

      Pad the shorter array with zeros so both have the same length, then add index by index.

      n = max(len(P), len(Q))
pad P and Q with 0 to length n
for k = 0 to n-1:
    R[k] = P[k] + Q[k]

      Subtraction

      R[k] = P[k] − Q[k]

      Same alignment as addition. Only the sign of Q’s coefficients changes.

      n = max(len(P), len(Q))
pad P and Q with 0 to length n
for k = 0 to n-1:
    R[k] = P[k] - Q[k]

      Multiplication

      R[i+j] += P[i] × Q[j]

      Every term of P meets every term of Q. Powers add (xi·xj = xi+j), so the product is added at index i + j. This is convolution.

      R = array of size
    deg(P)+deg(Q)+1, all 0
for i = 0 to deg(P):
  for j = 0 to deg(Q):
    R[i+j] += P[i] * Q[j]

      Division

      P = Q × quotient + remainder

      Long division on arrays. Work from the highest index down, divide the leading term by Q’s leading coefficient, then subtract.

      r = copy of P
for k = deg(r) down to deg(Q):
    t = r[k] / Q[deg(Q)]
    quotient[k - deg(Q)] = t
    for j = 0 to deg(Q):
        r[k - deg(Q) + j] -= t * Q[j]
remainder = r[0 .. deg(Q)-1]

      Derivative and integral

      d/dx: k·P[k] → index k−1
      ∫: P[k]/(k+1) → index k+1

      Calculus becomes an index shift plus a multiply or divide. The integral keeps index 0 free for the constant C.

      derivative:
for k = 1 to n:
    D[k-1] = k * P[k]
integral:
for k = 0 to n:
    I[k+1] = P[k] / (k+1)

      Evaluation (Horner)

      P(x) = a0 + x(a1 + x(a2 + …))

      Nested form needs only n multiplications and n additions, instead of computing every power of x.

      result = 0
for k = n down to 0:
    result = result * x + P[k]

      About the project

      Project details

      • Title: Polynomial Operation System Using Arrays
      • Subject: Data Structures
      • Core concept: Arrays (index = exponent)
      • Language: JavaScript (with HTML5 and CSS3)
      • Students: Atul Khandekar, Shivam Wande, Sneha Ghule, Adhrika Kumari

      Objectives

      • Represent polynomials with a one-dimensional array.
      • Implement addition, subtraction and multiplication.
      • Handle different degrees, zero and negative coefficients.
      • Show every step so the algorithm can be explained.

      Learning outcomes

      • Map a mathematical idea onto a data structure.
      • Analyse time complexity: O(n) for add and subtract, O(n·m) for multiply.
      • Recognise the space trade-off of array storage.
